# Ponchia

I work on cloud architecture and platform engineering, and build small, practical tools for developers and the web.

## Open-source projects

- **[Bronto UI](https://github.com/Ponchia/bronto-ui)** — CSS-first, framework-independent interface components for dashboards, tools, and reports. [Demo and documentation](https://ponchia.github.io/bronto-ui/).
- **[Bronto Annotations](https://github.com/Ponchia/bronto-annotations)** — headless TypeScript annotations for charts and diagrams, including collision-aware placement and connectors. [Examples](https://ponchia.github.io/bronto-annotations/).
- **[Bronto Layout](https://github.com/Ponchia/bronto-layout)** — responsive layout contracts and browser-native diagnostics for developers and coding agents.
- **[Vaultwarden ESO Provider](https://github.com/Ponchia/vaultwarden-eso-provider)** — an External Secrets Operator webhook provider for Bitwarden Password Manager and Vaultwarden.

## Browser experiments

**[Sense6](https://sense6.net/en/)** is a free collection of five short browser experiments about colour perception, reaction time, hearing, and visual detail, with research guides in multiple languages. Results depend on the device and conditions; these experiments are recreational and **not medical tests or diagnoses**. Individual answers and results stay in your browser. The Sense6 source repository is currently private while the project is in development.
