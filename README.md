# Ponchia

Cloud architect and platform engineer working on Kubernetes, cloud infrastructure, and open-source tools for developers and the web.

## Bronto · Developer tools

- **[Bronto UI](https://github.com/Ponchia/bronto-ui)** — CSS-first, framework-independent UI components for developer tools and dashboards. [Documentation and demo](https://ponchia.github.io/bronto-ui/).
- **[Bronto Annotations](https://github.com/Ponchia/bronto-annotations)** — headless annotations for diagrams and charts, with collision-aware placement, connectors, and optional renderers. [Examples](https://ponchia.github.io/bronto-annotations/).
- **[Bronto Layout](https://github.com/Ponchia/bronto-layout)** — browser-native responsive layout contracts and diagnostics for developers and coding agents. *Beta.*
- **[Bronto Visual Models](https://github.com/Ponchia/bronto-visual-models)** — persistent, editable diagrams, charts, and timelines with typed operations and optional renderers. [Interactive demo](https://ponchia.github.io/bronto-visual-models/). *Beta.*
- **[Bronto Pulse](https://github.com/Ponchia/bronto-pulse)** — project analytics and evidence reports for GitHub, npm, Cloudflare, and Search Console. *Public source preview; live integrations are still being validated.*

## Infrastructure and workflows

- **[Vaultwarden ESO Provider](https://github.com/Ponchia/vaultwarden-eso-provider)** — an External Secrets Operator webhook provider for Bitwarden Password Manager and Vaultwarden.
- **[Web Tooling](https://github.com/Ponchia/web-tooling)** — reusable GitHub Actions checks for independent static websites.
